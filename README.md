# odin-recipes
Recipes Website
Introduction

This project consists of building a basic recipes website using HTML. The website will feature a homepage with links to a selection of recipes, each leading to its own page with information about the dish.

The website will not look particularly polished by the end of the project, as CSS will not be used initially. The main goal is to focus on HTML fundamentals and build a solid foundation for future web development projects.

Skills Demonstrated

By completing this project, I will have demonstrated my ability to:

Create the structure of a webpage using HTML.
Use HTML elements such as headings, paragraphs, lists, and links.
Create multiple webpages and connect them through navigation links.
Organize content in a clear and meaningful way.
Work with images and provide appropriate alternative text.
Structure a basic website using semantic and accessible HTML practices.
Organize project files and directories effectively.
Technologies Used
HTML5 — To structure and organize the website's content.
Project Goals

The primary goal of this project is to practice and reinforce fundamental HTML skills by creating a simple, functional recipes website. Styling with CSS will be introduced in future projects as I continue developing my web development skills.
